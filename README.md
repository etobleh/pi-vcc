# pi-vcc

forked from [@sting8k/pi-vcc](https://www.npmjs.com/package/@sting8k/pi-vcc) to fix some architectural issue that does not adapt pi well.

## is this better than @sting8k/pi-vcc?

probably not

## install

whatever way you install pi packages:

```bash
pi install npm:@etobleh/pi-vcc
```

or git:

```bash
pi install https://github.com/etobleh/pi-vcc
```

or just run it once without installing:

```bash
pi -e https://github.com/etobleh/pi-vcc
```
